## AIC8800 Linux driver (GPL-2.0-only)

Hardware facts in `Sources/Shared/aic8800.h` (USB IDs, message ids and layouts, framing, addresses, firmware
names) come from github.com/shenmintao/aic8800d80 (derived from AICsemi's reference driver; AIC approved
GPLv2 for the released source, see that repository's README and radxa-pkg/aic8800). Files ported from it in
later phases keep their original copyright lines and are listed here:

- `Sources/Shared/aic_fwload.h`, `Sources/Shared/aic_fwload.c`: from `aic_load_fw/aicbluetooth.c`
  (`aicbt_patch_table_alloc`, `aicbt_patch_info_unpack`, `aicbt_patch_table_load`,
  `rwnx_plat_bin_fw_upload_android`) and `aic_load_fw/aic_compat_8800d80.c` (`aicwf_patch_config_8800d80`,
  `patch_tbl_d80`, `system_config_8800d80`), on branches `main` and `legacy-mcu1` (the MCU1 / product
  0x8820 profile). Copyright (C) AICSemi 2018-2020. GPL-2.0-only.
- `Sources/Shared/aic_fmac.h`, `Sources/Shared/aic_fmac.c`: from `aic8800_fdrv/lmac_msg.h` (message ids, layouts),
  `rwnx_msg_tx.c` (request builders), `rwnx_platform.c` (user-config defaults, parser and key table) and
  `aicwf_compat_8800d80.c`, `rwnx_mod_params.c` (capabilities), `rwnx_main.c` (channel tables) and `regdb.c`
  (the "00" rules), branch `legacy-mcu1`. Copyright (C) AICSemi 2018-2020; Copyright (C) RivieraWaves 2012-2019 for the
  rwnx_* files. GPL-2.0-only. `Tests/fmac_golden.h` holds bytes generated by running that code.
- `Sources/Shared/aic_data.h`, `Sources/Shared/aic_data.c`: from `aic8800_fdrv/rwnx_tx.c` (`rwnx_tx_push`,
  `rwnx_tid2hwq`, the USB TX path), `ipc_shared.h` (`struct hostdesc`), `rwnx_rx.c` / `rwnx_rx.h`
  (`struct hw_rxhdr`, `rwnx_rxdataind_aicwf`), `aicwf_usb.c` and `usb_host.c` (TX confirmations), branch
  `legacy-mcu1`. Copyright (C) AICSemi 2018-2020; Copyright (C) RivieraWaves 2012-2019. GPL-2.0-only.
- The connect, key and control-port messages in `aic_fmac.c` come from `rwnx_send_sm_connect_req`,
  `rwnx_send_key_add`, `rwnx_send_me_set_control_port_req` and `rwnx_send_sm_disconnect_req` (`rwnx_msg_tx.c`)

  is GPL-2.0-only too.

  `system_config_8800d80`; that part of the file is GPL-2.0-only.

## Firmware

The AIC8800D80 firmware (`fw_patch_*`, `fw_adid_*`, `fmacfw_*`) is AICsemi's. It has no stated open-source
license, so it is **not** part of this repository; `scripts/fetch-firmware.sh` downloads it onto the user's
Mac from the driver repository at pinned commits (SDK V5 set from `main`, SDK V3 set from `legacy-mcu1`, which
that branch imported from radxa-pkg/aic8800 commit 254d47e) and verifies SHA-256 hashes.
